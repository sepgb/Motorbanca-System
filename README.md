## BATIS — Banca Tracking and Information System

A platform that helps passengers traveling between Talim Island and mainland Binangonan check motorbanca schedules, queue status, and passenger information at Binangonan Port. Passengers can view real-time queue updates and passenger counts, helping them know which motorbanca is preparing to depart and reduce unnecessary waiting at the port.

<b>Note:</b> This project is a personal project created for educational purposes.
